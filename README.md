# 🛡️ AI Phishing & Scam Link Detector

An end-to-end Machine Learning web application that analyzes URLs in real time to detect phishing/scam links and explains security risk indicators.

### 🚀 Live Demo
👉 **[Click here to try the Live Web App](https://verisafe-ai.streamlit.app/)**

### 🛠️ Tech Stack
- **Language:** Python
- **Machine Learning:** Scikit-Learn (Random Forest Classifier), Pandas
- **Frontend & Deployment:** Streamlit Community Cloud

### ✨ Key Features
- **Real-Time Risk Scoring:** Predicts phishing probability score for any given URL.
- **Explainable AI (XAI):** Clearly highlights why a link is flagged as risky (missing HTTPS, suspicious keywords, abnormal hyphens, or hidden IP/symbols).
